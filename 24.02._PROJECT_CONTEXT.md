# PROJECT_CONTEXT

## TL;DR
**filmfreaks** ist eine iOS-App (SDK: `iphoneos`, Deployment Target: **iOS 26.0**) zum Tracken von Filmen (gesehen + Backlog) mit **pro User Ratings**, **Gruppen/Sharing via CloudKit**, **Statistiken**, **Custom Goals** und **Filmabend-Planung (Movie Nights)**. Einstiegspunkt ist `filmfreaks/filmfreaksApp.swift` (SwiftUI `@main`), Sync läuft primär über **direkte CloudKit-Records** + **lokale JSON-Persistenz**.

## Key Concepts / Domänenbegriffe
- **Watched / Backlog**: Zwei Listen pro Gruppe, gespeichert als `[Movie]`. (`filmfreaks/MovieStore/MovieStore.swift`)
- **Rating**: Bewertung pro Reviewer, inkl. Kriterien-Scores + optionalem Fazit (1–10). (`filmfreaks/Movie.swift`)
- **Active Member**: aktuell ausgewählter Reviewer/User für UI-Filter & Rating-Edit. (u.a. `filmfreaks/UserStore.swift`)
- **Group / groupId**:
  - *Legacy/public*: groupId ist ein String (Invite-Code o.ä.) → **Public DB** (CloudKit) + `groupId` Feld.
  - *Sharing/Zone group*: groupId ist UUID-like → **Private/Shared DB + Zone**, zwingend mit **GroupContext**. (`filmfreaks/CloudKitRouting.swift`, `filmfreaks/GroupContext.swift`)
- **GroupContext**: Persistierte Routing-Metadaten (scope + zoneName + ownerName), damit Stores korrekt in private/shared DB routen. (`filmfreaks/GroupContext.swift`)
- **Movie Night**: Event (Termin + optional Film) + pro User Response + Activity Events. (`filmfreaks/MovieNights/*`)
- **Activity Feed**: vereinheitlichte Events aus Movies/Ratings + MovieNights (Preview auf Home). (`filmfreaks/Content/GroupActivityEvent.swift`, `filmfreaks/Content/ContentActivityPreviewModel.swift`)
- **Custom Goals**: generisches Modell (type + rule + target + year-scope) als versioniertes Payload pro Gruppe. (`filmfreaks/ViewingCustomGoal.swift`, `filmfreaks/ViewingCustomGoalsPayload.swift`, `filmfreaks/CloudKitGoalStore.swift`)

## Sync/Storage
### Lokal (offline-first)
- **Movies/Backlog/Users**: JSON-Dateien in Application Support via `filmfreaks/PersistenceManager.swift`
  - Struktur: `~/Library/Application Support/FilmFreaks/groups/<safeGroupId>/(movies_watched|movies_backlog|users).json`
  - Writes: debounced + atomic (siehe `PersistenceManager.scheduleWrite(...)`)
  - Migration: einmalige Migration von UserDefaults → Disk (`migrateFromUserDefaultsIfNeeded()`)
- **Movie Nights**: 1 JSON Snapshot (`MovieNightLocalPersistence`, actor) in Application Support
- **UserDefaults**: Settings, Tokens, kleine Caches
  - GroupContexts: `GroupContextStore` (`filmfreaks/GroupContext.swift`)
  - Zone Change Tokens: `CloudKitZoneChangeTokenStore` (`filmfreaks/CloudKitZoneChangeTokenStore.swift`)
  - Display Settings: `filmfreaks/DisplaySettings/*`
  - TTL Caches: z.B. `PersonPopularityStore` (`filmfreaks/PersonPopularityStore.swift`)

### CloudKit (direkt, kein SwiftData/CoreData)
- **Routing**: `filmfreaks/CloudKitRouting.swift`
  - Ohne groupId → Public DB
  - UUID-like groupId → Zone-basiert (private/shared) und **GroupContext muss vorhanden sein**, sonst `CloudKitRoutingError.groupContextNotReady`
- **Record Types (aus Code ableitbar)**
  - Movies: `"Movie"` (`filmfreaks/CloudKitMovieStore/CloudKitMovieStore.swift`)
  - Ratings: `"MovieRating"` (`filmfreaks/CloudKitRatingStore/CloudKitRatingStore+Schema.swift`)
  - Group members: `"GroupMember"` (`filmfreaks/CloudKitUserStore.swift`)
  - Groups: `"FFGroup"` (`filmfreaks/CloudKitGroupStore/CloudKitGroupStore.swift`)
  - Goals: `"ViewingGoal"`, `"ViewingCustomGoals"` (`filmfreaks/CloudKitGoalStore.swift`)
  - Movie nights: `"MovieNightEvent"`, `"MovieNightResponse"`, `"MovieNightActivity"` (`filmfreaks/CloudKitMovieNightStore/CloudKitMovieNightStore.swift`)
- **Incremental Sync (Zone Changes)**:
  - Wrapper: `filmfreaks/CloudKitZoneChanges.swift`
  - Token Persistenz: `filmfreaks/CloudKitZoneChangeTokenStore.swift`
  - Nutzung (Beispiele):
    - Movies: `filmfreaks/CloudKitMovieStore/CloudKitMovieStore+ZoneChanges.swift`
    - Ratings: `filmfreaks/CloudKitRatingStore/CloudKitRatingStore+ZoneChanges.swift`
    - Movie nights: `filmfreaks/CloudKitMovieNightStore/CloudKitMovieNightStore+ZoneChanges.swift`
- **Push/Subscriptions**
  - Background mode: `remote-notification` (`filmfreaks/Info.plist`)
  - Subscriptions: `filmfreaks/CloudKit/CloudKitActivitySubscriptionManager.swift`
  - Push fetch entry: `filmfreaks/CloudKitShareAppDelegate.swift` → `CloudKitActivityPushFetchCoordinator`

### Offline-Verhalten / Pending Changes

## Conventions (Naming, Patterns, Do/Don’t)
- File-Splitting via `+` Extensions pro Concern (Beispiele):
  - `MovieStore/MovieStore+CloudSync.swift`, `CloudKitMovieStore/CloudKitMovieStore+*.swift`, `DisplaySettings/DisplaySettings+*.swift`
- Stores:
  - i.d.R. `@MainActor final class …: ObservableObject`
  - `@Published` Outputs, side-effects in `didSet` nur wenn nötig (siehe `MovieStore+Persistence.swift`)
- CloudKit:
  - Reine Access-Layer als `struct` (z.B. `CloudKitMovieStore`) + focused extensions
  - Zone-based incremental sync über `CloudKitZoneChanges` + `CloudKitZoneChangeTokenStore`
- Routing Safety:
  - UUID-like `groupId` **darf nicht** in Public DB fallen (`CloudKitRouting.requiresGroupContext`)
- Do:
  - Derived Lists/Activity **aus dem Render-Pfad raus** (siehe `ContentMovieItemsModel`, `ContentActivityPreviewModel`)
- Don’t:
  - Secrets direkt in Git commiten (`Secrets.xcconfig`)
  - Unscoped `Task {}` ohne Cancellation, wenn der View mehrfach erscheinen kann (siehe Hotspots)

## Quick Wins (max. 10, konkret)
1. **Secrets raus aus Repo**: `filmfreaks/Secrets.xcconfig` enthält einen echten `TMDB_API_KEY`. Rotieren + `Secrets.local.xcconfig` einführen und gitignoren. (Files: `filmfreaks/Secrets.xcconfig`, `filmfreaks/Debug.xcconfig`, `filmfreaks/Release.xcconfig`)
2. **MovieStore Cloud Merge O(n²) reduzieren**: `MovieStore+CloudSync.loadFromCloud()` arbeitet mit `removeAll` in Loops → Dict/Index-basiertes Merge. (`filmfreaks/MovieStore/MovieStore+CloudSync.swift`)
3. **Unscoped Tasks in Views härten**: z.B. `MovieDetailView+Lifecycle.handleOnAppear()` startet `Task { await loadDetails() }` ohne Cancellation/Guard. (`filmfreaks/MovieDetail/MovieDetailView+Lifecycle.swift`)
4. **CloudKit Query Indexes verifizieren**: Public-DB Queries filtern nach `groupId` → CloudKit Index nötig. Status im Dashboard ist **UNKNOWN**. (u.a. `filmfreaks/CloudKitMovieStore/CloudKitMovieStore+Routing.swift`)
5. **Logging konsolidieren**: `print` in Sync-Pfaden durch `Logger` ersetzen (Filterbarkeit). (z.B. `MovieStore+CloudSync.swift`)
6. **Sync-Transparenz konsistent**: MovieStore/UserStore/MovieNightStore haben Sync-Meta an mehreren Stellen; Keying/UX vereinheitlichen. (Files: `MovieStore+Persistence.swift`, `UserStore.swift`, `MovieNightStore+CloudFlush.swift`)
7. **GroupContext Lifecycle prüfen**: Bei Share-Accept sollte GroupContext sofort persistiert werden; Race-Conditions markieren. (Files: `CloudKitGroupStore.swift`, `GroupContext.swift`, `CloudKitRouting.swift`)
8. **View Splits für Merge-Konflikte**: `ContentView.swift`, `MovieSearchView.swift`, `SettingsView.swift`, `GroupSettingsView.swift` weiter modularisieren. (Paths siehe Big Files List)
9. **Background Fetch begrenzen**: Push-Fetch (`CloudKitActivityPushFetchCoordinator`) sollte strikt coalescen + limitieren, damit keine parallelen Fetches entstehen. Status ist **UNKNOWN**, je nach Implementierung. (Files: `filmfreaks/CloudKit/CloudKitActivityPushFetchCoordinator.swift`)
10. **Test Harness**: Add minimal integration tests für (a) Persistence migration (b) CloudKitRouting.requiresGroupContext Guard — aktuell **UNKNOWN**, ob Tests das abdecken. (Targets: `filmfreaksTests`)
